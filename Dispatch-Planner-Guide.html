Dispatch Planner Guide

Dispatch Planner

dispatch-seven-xi.vercel.app Chrome → ⋮ → “Add to Home screen”. Then it opens like an app.

Every morning

  1. Top bar: type People today, Autos today, Porters today.
  2. On each client getting a delivery, press Send today.Type box size and number. Tick ⚡ Urgent if it must reach fast.
  3. Read the answer: “Send 3 people on 3 routes + 1 Porter”.If it says “book 2 more autos”, book them and change the number.
  4. On each route card, choose Who takes this?
  5. Press WhatsApp on the card to send the boy his route.He presses Navigate in the message. Google Maps takes him stop by stop.
  6. Evening: press Clear day.

Symbols

  1. ⚡ Urgent. Goes first. LATE in red = cannot reach in time.
  2. Route 1, 2, 3 = a boy. Auto = hired auto. Porter = Porter trip.
  3. Map see the route. Navigate open in Google Maps. Move… send a stop to another route.

If a client is “not on map yet”

Press Locate. Still not found? Press Pin, move the map until the pin is on the shop, press Save. Done once, remembered forever.

Same shop, two gates

Press Send today on that client twice. Write the gate name each time.
